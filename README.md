# Simple Interest Calculator

## Description

A simple interest calculator that calculates the simple interest and total amount based on the principal amount, rate of interest, and time period.

## Formula

Simple Interest:

**SI = (P × R × T) / 100**

Where:

* **P** = Principal amount
* **R** = Rate of interest
* **T** = Time period

Total Amount:

**Amount = P + SI**

## Example

If:

* Principal = 10,000
* Rate = 5%
* Time = 2 years

Then:

**Simple Interest = (10,000 × 5 × 2) / 100 = 1,000**

**Total Amount = 10,000 + 1,000 = 11,000**
